Update FAQ

What to know about version 1.1.0.

Is WeLookup 1.1.0 already active?add

Yes. If Chrome opened this page after an extension update, WeLookup 1.1.0 is already installed and active. No further action is required.

What is new in WeLookup 1.1.0?add

WeLookup 1.1.0 introduces four focused views: Overview, Technology, Products and Audit. It also adds clearer loading states, stronger Shopify research tools, catalog scanning and AI-readiness checks.

Does WeLookup work on stores that are not built with Shopify?add

Yes. Technology detection works across public storefronts. Shopify-specific theme, product catalog and AI-readiness features appear only when Shopify is confirmed and the required public signals are available.

How many apps and technologies can WeLookup detect?add

The current detection library contains 8,244 technology signatures, including 873 Shopify apps.

Does WeLookup upload or store scan results?add

No scan results are uploaded to or stored on WeLookup servers. Analysis runs locally in Chrome and results stay on your device.

How large is the WeLookup Chrome extension?add

The current Chrome Web Store package is 1.35 MiB. WeLookup is built to remain lightweight while keeping its core research tools close to the page.
